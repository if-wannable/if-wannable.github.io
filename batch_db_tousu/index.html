豆瓣批量投诉工具

举报讨论本身（非回复）｜ Cookie 不离开浏览器，全程浏览器端运行

使用方法

  1. 将下方按钮拖到浏览器书签栏：
    🔍 豆瓣投诉
    （如果书签栏没显示，按 Cmd+Shift+B 或 Ctrl+Shift+B 显示书签栏）
  2. 打开 douban.com 并确保已登录
  3. 在豆瓣任意页面点击书签栏的 "🔍 豆瓣投诉"
    工具面板会出现在页面右上角，自动获取 Cookie，无需手动复制

功能说明

  • 举报对象：讨论本身（原始帖），非回复
  • 举报理由：两级下拉选择（大类 -> 小类），所有讨论共用同一理由
  • 链接格式：支持标准 URL 和 doubanapp/dispatch 格式
  • 批量输入：每行一个 URL，或上传 CSV/TXT 文件
  • 进度显示：进度条 + 成功/失败统计 + 逐条日志
  • 限速：默认 800ms 间隔防风控

备用：控制台方式

如果书签方式不工作，可以在豆瓣页面 F12 控制台粘贴以下代码：

var s=document.createElement('script');s.src='https://if-wannable.github.io/batch_db_tousu/tool.js';document.head.appendChild(s);

手机端使用

iPhone Safari：设置 -> Safari -> 高级 -> 启用"网页检查器"，连接 Mac 后在 Mac Safari 开发菜单中粘贴代码

Android Chrome：在 douban.com 页面打开菜单 -> 分享 -> 复制链接，然后将 bookmarklet 的 javascript: 代码粘贴到地址栏
