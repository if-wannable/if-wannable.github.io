db批量投诉工具

举报讨论本身（非回复）｜ Cookie 不离开浏览器，全程浏览器端运行

使用方法

  1. 将下方按钮拖到浏览器书签栏：
    🔍 db投诉
    （如果书签栏没显示，按 Cmd+Shift+B 或 Ctrl+Shift+B 显示书签栏）
  2. 打开 douban.com 并确保已登录
  3. 在db任意页面点击书签栏的 "🔍 db投诉"，工具面板自动出现

功能说明

  • 举报对象：讨论本身（原始帖），非回复
  • 用户投诉：可切换到用户投诉 Tab，批量处理用户主页并支持单选/多选理由
  • 举报理由：支持单理由，以及 black_pool 中的三种多理由组合
  • 小驼组合拳：侮辱谩骂、挂人引战、网暴谩骂、诱导不良行为
  • 小兔组合拳：引战、饭圈干扰舆论、侮辱谩骂
  • 富贵组合拳：网暴歧视、人身攻击、饭圈造谣爆料
  • 链接格式：支持标准 URL 和 doubanapp/dispatch 格式
  • 批量输入：在文本框中每行粘贴一个 URL
  • 进度显示：进度条 + 成功/失败统计 + 逐条日志
  • 限速：默认 800ms 间隔；每 20 条举报请求暂停 30 秒，并自动递增间隔
