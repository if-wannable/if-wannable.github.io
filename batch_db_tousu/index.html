豆瓣批量投诉工具

举报讨论本身（非回复）｜ Cookie 不离开浏览器，全程浏览器端运行

电脑端

  1. 将下方按钮拖到浏览器书签栏：
    🔍 豆瓣投诉
    （如果书签栏没显示，按 Cmd+Shift+B 或 Ctrl+Shift+B 显示书签栏）
  2. 打开 douban.com 并确保已登录
  3. 在豆瓣任意页面点击书签栏的 "🔍 豆瓣投诉"，工具面板自动出现

手机端 设置一次，以后去豆瓣点书签即可

点上面按钮复制，后面要用

第二步：在豆瓣创建书签 iOS Safari

  1. 打开 douban.com（确保已登录）
  2. 点底部 分享按钮（方框+向上箭头），选 "添加书签"
  3. 点底部 书签按钮（打开的书本图标），找到刚保存的书签
  4. 点右下角 "编辑"，点击刚保存的书签
  5. 将 URL 栏清空，粘贴刚才复制的代码
  6. 将 标题 改为"豆瓣投诉"，点"完成"

第二步：在豆瓣创建书签 Android Chrome

  1. 打开 douban.com（确保已登录）
  2. 点地址栏右侧 星标 添加书签，选"书签栏"
  3. 点右上角 三点菜单 -> 书签 -> 找到刚保存的书签
  4. 点击该书签右侧 三点 -> "编辑"
  5. 将 URL 栏清空，粘贴刚才复制的代码，点"保存"

第三步：使用

以后每次使用：打开豆瓣任意页面 -> 点书签 -> 选"豆瓣投诉" -> 工具面板自动出现

功能说明

  • 举报对象：讨论本身（原始帖），非回复
  • 举报理由：两级下拉选择（大类 -> 小类），所有讨论共用同一理由
  • 链接格式：支持标准 URL 和 doubanapp/dispatch 格式
  • 批量输入：每行一个 URL，或上传 CSV/TXT 文件
  • 进度显示：进度条 + 成功/失败统计 + 逐条日志
  • 限速：默认 800ms 间隔防风控
